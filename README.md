# Privacy Policies

Ce dépôt contient les politiques de confidentialité publiées par Yassdev81.

## Ajouter une politique

Créez un dossier au nom de l'application, par exemple `nom-de-l-app/`, puis ajoutez sa page dans `nom-de-l-app/index.html`. Ajoutez ensuite un lien vers cette page dans `index.html`.

## Activer GitHub Pages

Dans GitHub, ouvrez `Settings` → `Pages`, sélectionnez `Deploy from a branch`, puis la branche `main` et le dossier `/(root)`.

L'URL finale attendue pour CarTodo est :

<https://yassdev81-code.github.io/privacy-policies/cartodo/>
